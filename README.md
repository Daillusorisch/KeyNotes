# Key Notes

WIP key notes of plasma physics. I plan to gradually collect all my notes from LaTeX to html.

This was originally generated by [Books.jl](https://huijzer.xyz/Books.jl/), and then shifted to [Quarto](https://quarto.org/).

## 中文版本 / Chinese edition

The Chinese source is in `zh/`. To build the English book and Chinese HTML edition together, install Quarto and run:

```sh
python scripts/build_bilingual.py
```

The combined site is written to `docs/`, with the Chinese edition under `docs/zh/`. Use `python scripts/build_bilingual.py --check` to check inputs without rendering. Some image files referenced by the original notes are not present in this repository; the check lists them.
