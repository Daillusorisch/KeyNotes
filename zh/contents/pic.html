30  粒子网格法

30.1 相空间采样

设 \(\hat{f}(\mathbf{z})\) 是归一化的一般概率密度函数： \[ \int_\Omega \hat{f}(\mathbf{z})dV = 1 \]

现在根据 \(\hat{f}(\mathbf{z})\) 用 \(N\) 个标记粒子对相空间采样，则_标记粒子分布_ \(g\) 为： \[ g(\mathbf{z}) = N\hat{f}(\mathbf{z}) \] 而一个标记粒子占据的相空间体积元为 \[ dV_i = \frac{1}{g(\mathbf{z}_i)} \] 其中 \(\mathbf{z}_i\) 是标记粒子的相空间坐标，\(dV_i\) 是它占据的体积元。

将标记粒子的权重定义为其占据的相应相空间体积内的物理粒子数： \[ w_i = f(\mathbf{z}_i)dV_i = \frac{f(\mathbf{z}_i)}{g(\mathbf{z}_i)} \]

这个标记粒子分布可以表示总分布 \(f\) 或 \(\delta f\)。（？？？）

现在可以求相空间中分布函数的矩（例如密度），积分的蒙特卡洛近似如下： \[ M(A) = \int_\Omega A(\mathbf{z})f(\mathbf{z})dV = \sum_{i=1}^{N}A(\mathbf{z}_i)w_i + \mathcal{\frac{1}{\sqrt{N}}} \] 其中 \(N\) 是相空间区域 \(\Omega\) 内的标记粒子数。这种蒙特卡洛近似使许多问题的粒子模拟成为可能，即使在三维情况下也是如此，代价是引入量级为 \(N^{-1/2}\) 的误差。

30.2 人为缩放

表征等离子体系统的常见尺度：

  • 系统的全局尺度 \(d_g\)：在磁层中以磁层顶的迎风距离表征，在日冕中以太阳半径的一定比例表征，在托卡马克中以系统长度表征。

  • 以离子惯性长度 \(d_i\) 表征的离子动理学尺度 \[ d_i = \sqrt{\frac{m_i}{n_i q_i^2 \mu_0}} = \frac{m_i}{q_i}\sqrt{\frac{1}{\rho_i \mu_0}} \] 以及离子回旋半径 \[ r_i = \frac{m_i v_{\mathrm{th},i}}{q_i B} = \frac{m_i}{q_i}\frac{\sqrt{p_i/\rho_i}}{B} \]

  • 以电子趋肤深度 \(d_e\) 表征的电子动理学尺度 \[ d_e = \sqrt{\frac{m_e}{n_e q_e^2 \mu_0}} = \frac{m_e}{q_e}\sqrt{\frac{1}{\rho_e \mu_0}} \]

  • 以德拜长度 \(\lambda_D\) 表征的最小等离子体尺度 \[ \lambda_D = \sqrt{\frac{\epsilon_0 v_{\mathrm{th},e}^2}{q_e^2 n_e}} = \frac{m_e}{q_e}\frac{\epsilon_0 p_e}{\rho_e} \] 其中 \(v_{\mathrm{th},e}=\sqrt{p_e / \rho_e}\) 是电子热速度。

通常，\(d_i\) 比 \(d_g\) 小几个数量级，而 \(d_e\) 更小。如果我们关心全局等离子体系统与动理学过程之间的相互作用，自然会问系统行为如何依赖于比值 \(d_g∕d_i\)。例如，在木卫三的磁层中，\(d_g∕d_i \sim 10\)，动理学效应对全局系统有不可忽略的贡献。另一方面，如果 \(d_g∕d_i\) 非常大，动理学效应大多会局限在一个小区域内。1

对于准中性等离子体，\(n_i = n_e \rightarrow \rho_i/\rho_e = m_i/m_e\)，\(q_i = q_e\)，\(p_i = p_e\)。离子尺度是相应电子尺度的 \(\sqrt{m_i/m_e}\) 倍。对于质子—电子等离子体，\(\sqrt{d_i/d_e} \approx 43\)。降低计算需求的一个常用技巧是人为减小质量比（\(1836 \ge d_i/d_e \ge 25\)）。就重联而言，我们发现该过程对质量比的依赖相对较弱。实际上，几乎所有数值研究，尤其是三维研究，都使用减小的离子—电子质量比。

Tóth 等 (2017年) 提出了另一种缩放方法，将离子和电子的质荷比增大一个动理学缩放因子 \(f\)，同时保持 MHD 量、质量密度 \(\rho_e\) 和 \(\rho_i\)、压力 \(p_e\) 和 \(p_i\)、整体速度 \(u_e\) 和 \(u_i\)、磁场 B 以及常数 \(\epsilon_0, \mu_0\) 和 c 不变。该缩放方法的一个优点是特征速度（整体速度、热速度、阿尔芬速度）不变；换句话说，这种_动理学缩放_不影响理想或电阻性 MHD。其直接结果是，不同 f 值下动理学尺度上的解相似，但空间和时间尺度与 f 成正比。

30.3 数值加热与热化

数值加热和数值热化都是 PIC 模拟中可能出现的数值伪效应，但它们代表不同的现象。注意，「加热」是一个泛称：实际上，对于隐式 PIC 格式，数值冷却更常发生。

  • 数值加热：
    • 机制：指离散化误差造成的系统总动能虚假增加。这通常源于粒子与定义在网格上的电场和磁场之间的相互作用。有限的网格尺寸和时间步长可能导致力的计算不准确，使粒子人为地获得能量。  
    • 影响：导致等离子体温度随时间发生非物理性的升高。这可能影响模拟稳定性并导致结果不准确。  
    • 例子：设想一个粒子在电场中加速。在真实等离子体中，粒子会平滑地获得能量；但在 PIC 模拟中，粒子可能「跳过」网格点，使获得的能量略高于预期。
  • 数值热化：
    • 机制：这是一种较为隐蔽的效应，与速度分布函数（VDF）人为弛豫至麦克斯韦分布有关。它由宏粒子因其有限尺寸和网格而产生的「数值碰撞」引起。即使总能量守恒，能量在粒子之间的分配方式也可能被人为改变。  
    • 影响：即使真实等离子体不会达到这种状态，它也会使系统趋于人为的热平衡。这可能掩盖动理学效应，并导致对输运性质的预测错误。
    • 例子：考虑注入等离子体的电子束。实际上，这一束流可能持续很长时间；但在 PIC 模拟中，数值碰撞可能使束流扩散，并比预期快得多地失去其鲜明特征。

主要区别：

  • 能量守恒：数值加热违反能量守恒，而即使能量守恒也可能发生数值热化。
  • 时间尺度：数值加热通常比数值热化发生得更快。
  • 分布函数：数值加热主要影响平均能量，而数值热化改变分布函数的形状。

缓解策略：

  • 增加宏粒子数：这可以减小模拟的颗粒性和数值碰撞的影响。   细化网格：更小的网格尺寸可以提高场计算的精度并减少离散化误差。
  • 使用高阶形状函数：它们能更准确地表示电荷密度，并减少数值加热。
  • 使用先进的 PIC 算法：有些算法旨在更精确地守恒能量或动量，从而减少数值伪效应。

30.4 计算成本

PIC 比直接 n 体方法更可行的关键在于降低了计算成本。对于系统中的 \(N\) 个宏粒子，直接方法的复杂度为 \(\mathcal{O}(N^2)\)，而 PIC 方法为 \(\mathcal{O}(N\log N)\)。忽略成对相互作用、考虑集体效应，特别是距离较远的粒子的集体效应，可以大致理解这是如何实现的。

一个常用技巧是采用减小的离子—电子质量比。在三维模拟中，计算成本与 \((m_i/m_e)^3\) 成比例。但要注意，在低质量比运行中（例如 \(m_i/m_e=25\)），电子热速度可能与阿尔芬速度相当，从而通过电子的朗道阻尼导致更强的波衰减。

30.5 δf 方法

考虑等离子体的一维空间、一维速度 Vlasov-Poisson 系统中单个不稳定波的增长率。能量守恒给出 \[ \frac{\mathrm{d}}{dt}\Big(\frac{\epsilon_0}{2}E(x)^2\Big) + \int q v E(x)f(x,v)dv = 0 \]

对于单个模态 \(E(x,t) = A(t)\sin(kx-\omega t)\)，增长率为 \[ \gamma = \frac{1}{A}\frac{\mathrm{d}A}{\mathrm{d}t} = -\int qvEfdv = -\sum_j q_j w_j E(x_j) \] 其中 \(w_j\) 是粒子权重。所有动理学信息都包含在标记粒子的位置分布中。

\(\delta-f\) 方法的思想是将总分布函数分解为两部分， \[ f = f_0 + \delta f,\quad |\delta f|\ll f_0 \] 并使粒子权重与扰动部分成正比， \[ w\propto \delta f,\quad w_j = \frac{\delta f(x_j, v_j)}{f(x_j, v_j)} \]

如果 \(f_0\) 的贡献已知，例如 \[ \int qvE f_0 dv = \int qvf_0(v) A \sin(kx-\omega t)dv = 0 \] 那么增长率可以写为 \[ \gamma = -\int qvE\delta f dv = -\int qvE\frac{\delta f}{f}f dv = \sum_j q_j v_j w_j E(x_j) \]

由于现在粒子权重与 \(\delta f/f\) 成正比，系统噪声将显著减小 \((\delta f/f)^2\) 倍；换句话说，在相同噪声水平下，所需的宏粒子数将减少 \((\delta f/f)^2\) 倍，其典型值为 \(\mathcal{O}(10^6)\)。当然，这要求先前的假设 \(|\delta f| \ll f\) 成立。

Journal of Geophysical Research: Space Physics 122 (10): 10～336. https://doi.org/10.1002/2017JA024189.
